## Project Files and Responsibilities
The individual project you submitted should follow the structure below. 

| Path | What to include |
| --- | --- |
| README.md | An introduction to your replication, the process of your replication. We will use AI agent to follow your instructions to check whether your project is truly feasible|
| report.pdf | Final research report. The specific requirements are on Professor Xiong's website.|
| AI_USE_DISCLOSURE.md | Document how AI was used at each stage of the research. The specific requirements are on Professor Xiong's website.|


| data/raw/ | Store the original input data used in the project. |
| data/processed/ | Store the processed data that you use in your empirical replication, like the regression here |

| code/run_all.py | You need to have a "run_all.py" to make sure that you can generate all the outputs(tables and figures) by running this single code|
| code/ others | You can have some other codes like functions or just some data cleaning code, but make sure that run_all.py is enough for the replication of results |


| outputs/tables/ | Store tables generated by the code. |
| outputs/figures/ | Store figures generated by the code. |

| skills/SKILL.md | Describe the Skill for reproducing the empirical results. Specify its purpose, input data, environment, execution steps, expected tables or figures, and how to check the results. |
| Other files in skills/ | Store scripts, configuration files, or reference materials needed by the Skill. |

## Recommended Workflow

1. Read the selected paper and identify its research question, hypothesis, and target results.
2. Document the data sources and preparation steps in data/README.md, then place the raw inputs in data/raw/.
3. Record the software and dependencies in environment/ so the project can run in a reproducible environment.
4. Write the scripts in code/. Use code/run_all.py (or the corresponding Stata or R entry point) to run the analysis from the raw data through to the final outputs.
5. Save generated tables and figures in outputs/, then write the report based on those results.
6. Complete AI_USE_DISCLOSURE.md with an accurate account of AI use and human verification.
7. Write skills/SKILL.md and follow its instructions to confirm that it can reproduce the main empirical results.
8. Run the entire project from the beginning. Check that the report matches the generated outputs and that the README paths and commands are correct.
